图标方案 · 5 版

统一规格：256 画布、Win11 圆角方块（半径 22%）、四周留 2px 透明边。
下面每个方案都给了 104 / 64 / 48 / 32 / 16 五档，最后一排是深色任务栏上的实际观感 —— 16px 能不能认出来，是这一轮唯一要过的关。

任务栏
一键优化

01　循环环

一个白环 + 一个青绿箭头，是「跑一次优化」最短的表达。删掉指针和刻度后只剩两个元素，边缘干净、缩小不糊。
代价：偏「刷新」，也可能被当成同步或重试按钮。

02　盾牌对勾

盾 = 守住系统，对勾 = 一切正常。轮廓最实，是五版里 16px 最清楚的。
代价是「盾」多半指向杀毒，和「清理加速」的联想没那么直接。

内存专用

03　内存条

直接画一根内存：白条 + 三块青绿颗粒，底下那道深色槽是接口。软件最核心的活就是管内存，这个形状在同类软件里也不撞。
代价：不如四格那样一眼「这是 Windows」。

04　闪电

琥珀色在蓝灰任务栏里最扎眼，缩到 16px 也还是一个亮点，不会糊成一团。
缺点：闪电被用滥了，容易被当成充电或网络加速器。

05　星芒

四角星是「清理完、焕然一新」的通用符号，形体单一、没有细节，16px 下仍然是一个清楚的星。
