Windows系统管家 · UI 设计稿

Windows 11 Fluent Design · 13 个板块 · 明暗双主题

按 Windows 11 原生规范重做：Mica 底、8px 圆角卡片、NavigationView 导航、系统强调色、Segoe UI Variable。丢掉之前那套「窄侧栏 + 小字号」的 Mac 风格。

设计令牌 外壳与导航 基础控件 概览CPU内存进程 磁盘网络体检垃圾清理 重复文件大文件启动项 软件设置

01设计令牌

颜色全部取自 Windows 11 系统语义色，不自定义品牌色。强调色跟随系统（用户可在 Windows 设置里改，应用自动同步）。
